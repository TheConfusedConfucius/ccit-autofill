# ccit-autofill
Chrome extension for autofilling passwords in the LAN website

## How to use it

Step 1: To use this extension, you can clone this repo and download it onto your PC. 

Step 2: Go to chrome://extensions, turn on Developer's mode, click on load unpack and select this folder (ensure it's fully         extracted and not in the .zip format).

Step 3: Click on the reload icon once and enable the extension.

Step 4: Go to any website you want which needs a username and password (though intended only for BPHC's LAN portal), click on the extension in the extensions group in the tab bar. 

Step 5: Enter the Account name, username and password (which will be stored locally on your PC, I assure you) and click on save. Now, reload the page.

Step 6: Now in your LAN Login page, you can see the account names saved in a popup box title "LAN AAutofill accounts: " (the AA is on purpose ;). 

# Note:

1) This can sometimes open on other websites too which have the username and password element's IDs the same as CCIT LAN's connecting page. 

2) You can just open any website where this extension is used i.e where the box of all the saved passwords popup (preferrably the LAN connecting portal), open dev tools (Ctrl + Shift + I) and go to Application > Storage > Extension storage > Local and see the passwords and usernames saved on your desktop.
